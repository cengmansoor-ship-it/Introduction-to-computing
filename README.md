# Introduction to Computing – Multi-Language Code Repository

Welcome to the Introduction to Computing repository!
This repo contains all source code, examples, and demonstrations used throughout the course.
The goal is to help beginners understand fundamental computing concepts using five programming languages.

📘 Covered Programming Languages

This course provides examples and problem-solving exercises in:

Python – Problem solving, logic building, algorithms

C – Procedural programming and low-level concepts

C++ – Object-oriented programming essentials

Java – OOP, structure, and application development

Dart – Modern programming and Flutter-ready foundations

All code presented in the course lectures is available in this repository.

📁 Repository Structure

Each language has its own folder:

/Python
/C
/C++
/Java
/Dart


Inside each folder, you will find:

Lecture code examples

Practice exercises

Problem-solving tasks

Additional notes where needed

🎯 Purpose of This Repository

This collection is designed for:

Students taking the Introduction to Computing course

Beginners who want to compare concepts across multiple languages

Learners practicing algorithmic thinking and programming fundamentals

Anyone exploring Python, C, C++, Java, or Dart with simple examples

🧑‍🏫 About the Course

The Introduction to Computing course teaches core concepts such as:

Computational thinking

Algorithms & problem solving

Programming basics

Variables, conditions, loops, functions, and some data structures

OOP fundamentals (in languages that support it)

🔗 How to Use This Repo

Browse by language

Run the examples

Try modifying the exercises

Compare how the same concept works in different languages
